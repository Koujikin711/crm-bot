# Лиды с Telegram-аккаунта (+992870631000)

Личные сообщения, которые приходят на этот аккаунт, обрабатываются **только по направлению Бизнес**: создаётся лид, назначается менеджер бизнеса, переписка идёт через бота (как с WhatsApp). Медицина с этого аккаунта не задействована.

## Шаг 1. API-ключи Telegram

1. Зайди на https://my.telegram.org и войди по номеру **+992877631000**.
2. Открой **API development tools**.
3. Создай приложение (любое название), получи **api_id** (число) и **api_hash** (строка).

## Шаг 2. Настройка переменных

В `.env` в корне проекта добавь (или задай переменные окружения):

```env
TELEGRAM_LEADS_PHONE=+992877631000
TELEGRAM_API_ID=твой_api_id
TELEGRAM_API_HASH=твой_api_hash
```

Опционально — путь к файлу сессии (по умолчанию `tg_leads_session` в папке проекта):

```env
TELEGRAM_SESSION_PATH=./tg_leads_session
```

## Шаг 3. Зависимости

```bash
pip install -r requirements.txt
```

(В списке уже есть `telethon`.)

## Шаг 4. Первый запуск

Запусти бота. В логах должно появиться что-то вроде:

```
tg_leads: task started for +992877631000
```

При **первом** запуске Telethon попросит код из Telegram (на номер или в приложении Telegram). Введи код в консоль — сессия сохранится в файл, при следующих запусках ввод кода не понадобится.

Если переменные не заданы, клиент просто не стартует, бот и WhatsApp работают как раньше.

## Как это работает

- Кто-то пишет в личку аккаунту +992877631000 → бот создаёт лид (или находит существующий), назначает менеджеру бизнеса и пересылает сообщение менеджеру в боте.
- Менеджер в боте нажимает «✍️ НАПИСАТЬ» по лиду и пишет текст/фото/голос — сообщение уходит лиду с аккаунта +992877631000.
- В «Начать диалог» можно ввести числовой Telegram ID лида — откроется переписка с ним.

## Важно

- Аккаунт +992877631000 должен быть свободен для использования Telethon (автоматизация). Не входи в него в других приложениях одновременно, чтобы не было конфликта сессий.
- Использование пользовательского API может противоречить правилам Telegram; риск блокировки при умеренном использовании обычно низкий.
