# Настройка Google Таблицы для базы лидов (SMS-рассылка)

При закрытии лида **бизнеса** (Оплатил / Думает / Отказ) менеджер отвечает на вопросы: Сфера, Боль клиента, Комментарий, Перезвон. Данные записываются в CRM и (если настроено) добавляются строкой в Google Таблицу.

## Шаг 1. Google Cloud — проект и API

1. Откройте [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте проект или выберите существующий.
3. В меню **APIs & Services** → **Library** найдите **Google Sheets API** и нажмите **Enable**.

## Шаг 2. Сервисный аккаунт (Service Account)

1. **APIs & Services** → **Credentials** → **Create Credentials** → **Service account**.
2. Укажите имя (например, `crm-bot-sheets`), нажмите **Create and Continue**, затем **Done**.
3. Откройте созданный сервисный аккаунт → вкладка **Keys** → **Add Key** → **Create new key** → **JSON** → **Create**. Файл JSON скачается.

## Шаг 3. Доступ к таблице

1. Откройте вашу Google Таблицу («БАЗА СМС рассылка» → лист «База данных лидов»).
2. Нажмите **Поделиться**.
3. В поле добавьте **email сервисного аккаунта** из скачанного JSON (поле `client_email`, вид `xxx@xxx.iam.gserviceaccount.com`).
4. Выдайте право **Редактор** → **Готово**.

## Шаг 4. Переменные окружения

- **GOOGLE_SHEET_ID** — ID таблицы из URL:  
  `https://docs.google.com/spreadsheets/d/ **176UpFHBawww6QJroJFFkImNYSepaSsjyUtYXQJdsY7c** /edit...`  
  Т.е. `176UpFHBawww6QJroJFFkImNYSepaSsjyUtYXQJdsY7c`.

- **GOOGLE_SHEET_TAB_NAME** — название листа (по умолчанию `База данных лидов`).

- **GOOGLE_CREDENTIALS_JSON** — **строка** с содержимым скачанного JSON-ключа (весь JSON в одну строку, без переносов или с экранированием).  
  На Amvera: в настройках проекта добавьте переменную и вставьте JSON. Если переменная пустая — запись в таблицу отключена, остальная работа бота не меняется.

## Колонки листа

Ожидаемый порядок колонок в листе «База данных лидов»:

| A       | B   | C     | D             | E             | F           | G        |
|---------|-----|-------|---------------|---------------|-------------|----------|
| Дата    | ФИО | Номер | Вид бизнеса   | Боль клиента  | Комментарий | Перезвон |

Строки добавляются в конец листа при каждом закрытии бизнес-лида (исход «Оплатил» или «Отказ»; «Думает» тоже записывается в CRM, в таблицу добавляется только при закрытии).

## Локальная проверка

В `.env` добавьте (подставьте свои значения):

```
GOOGLE_SHEET_ID=176UpFHBawww6QJroJFFkImNYSepaSsjyUtYXQJdsY7c
GOOGLE_SHEET_TAB_NAME=База данных лидов
GOOGLE_CREDENTIALS_JSON={"type":"service_account",...}
```

Перезапустите бота и закройте тестовый бизнес-лид — в таблице должна появиться новая строка.
