# Лиды с Telegram-аккаунта (+992870631000)

Личные сообщения, которые приходят на этот аккаунт, обрабатываются **только по направлению Бизнес**: создаётся лид, назначается менеджер бизнеса, переписка идёт через бота (как с WhatsApp). Медицина с этого аккаунта не задействована.

## Шаг 1. API-ключи Telegram

1. Зайди на https://my.telegram.org и войди по номеру **+992870631000**.
2. Открой **API development tools**.
3. Создай приложение (любое название), получи **api_id** (число) и **api_hash** (строка).

## Шаг 2. Настройка переменных

В `.env` в корне проекта добавь (или задай переменные окружения):

```env
TELEGRAM_LEADS_PHONE=+992870631000
TELEGRAM_API_ID=твой_api_id
TELEGRAM_API_HASH=твой_api_hash
```

Опционально — путь к файлу сессии (по умолчанию `tg_leads_session` в папке проекта):

```env
TELEGRAM_SESSION_PATH=./tg_leads_session
```

## Шаг 3. Зависимости

```bash
pip install -r requirements.txt
```

(В списке уже есть `telethon`.)

## Шаг 4. Первый вход (код из Telegram)

**Если бот запущен у тебя на компьютере** — при первом запуске `main.py` в том же терминале, где запущен бот, Telethon попросит код из Telegram. Введи его там — сессия сохранится.

**Если бот запущен на Amvera** — интерактивной консоли там нет, ввести код нельзя. Нужно один раз войти на своём ПК и загрузить сессию на Amvera:

1. На своём компьютере открой папку проекта CRM, в ней должен быть файл `.env` с `TELEGRAM_LEADS_PHONE`, `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`.
2. Открой **терминал** (консоль): перейди в папку проекта: `cd путь\к\CRM`.
3. Выполни:
   ```bash
   pip install -r requirements.txt
   python tg_login_once.py
   ```
4. В консоли появится запрос кода — код придёт в приложение Telegram на номер +992870631000. Введи код в эту же консоль и нажми Enter.
5. После успешного входа в папке проекта появится файл **`tg_leads_session.session`**. Его нужно добавить на Amvera:
   - В кабинете Amvera открой свой проект → настройки / секреты / файлы.
   - Если есть возможность добавить **секретный файл** (Secret file) или **том с файлами** — загрузи туда `tg_leads_session.session` так, чтобы при запуске бота он оказывался в корне проекта с именем `tg_leads_session.session`.
   - Либо положи файл в репозиторий в корень проекта и добавь в деплой (менее безопасно: сессия в репозитории). Лучше использовать секретный файл Amvera, если он есть.
6. Перезапусти приложение на Amvera. Бот подхватит готовую сессию и не будет запрашивать код.

**Если в логах Amvera видишь:** `EOF when reading a line` или запрос кода — это как раз случай выше: консоли нет, нужен файл сессии с ПК.

Если переменные не заданы на Amvera, клиент не стартует, бот и WhatsApp работают как раньше.

## Как это работает

- Кто-то пишет в личку аккаунту +992870631000 → бот создаёт лид (или находит существующий), назначает менеджеру бизнеса и пересылает сообщение менеджеру в боте.
- Менеджер в боте нажимает «✍️ НАПИСАТЬ» по лиду и пишет текст/фото/голос — сообщение уходит лиду с аккаунта +992870631000.
- В «Начать диалог» можно ввести числовой Telegram ID лида — откроется переписка с ним.

## Важно

- Аккаунт +992870631000 должен быть свободен для использования Telethon (автоматизация). Не входи в него в других приложениях одновременно, чтобы не было конфликта сессий.
- Использование пользовательского API может противоречить правилам Telegram; риск блокировки при умеренном использовании обычно низкий.
